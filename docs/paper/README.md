# Nokor Pass: Repeat Visits, Not Promotion

Draft preprint (LaTeX) describing the design this repository implements:
a national visitor substrate for Cambodia's tourism recovery — soulbound pass,
kRIEL/kUSD payments with escrow and disputes, site access, departure refund,
and the giftable Nokor Point.

Authors: Sengtha Chay, Langdy Khut, Mouniseyhak Va. Status: draft, not peer reviewed.

Build: `latexmk -pdf main.tex`
